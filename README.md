# House Price Prediction Using ML and Random Forest Regression

## Project Overview
This project focuses on predicting house prices based on various features of houses using machine learning (ML) techniques, specifically the **Random Forest Regression** algorithm. The dataset used in this project contains detailed information about various houses and includes features like the year of construction, square footage, number of bedrooms, and more. The goal is to build a model that can predict the **SalePrice** of a house based on these features.

## Key Features of the Project:
- **Data Quality Analysis**: The project includes data quality checks, including identifying and handling missing values, duplicated rows, and ensuring that certain columns contain unique values.
- **Predictive Modeling**: A **Random Forest Regressor** is trained to predict the sale price of a house based on its features.
- **Evaluation**: The model's performance is evaluated using metrics like **R-squared** and **Mean Absolute Error (MAE)**.

## Dataset
The dataset used in this project is the **Ames Housing dataset**, which contains information about various houses in Ames, Iowa.

### Key Columns:
- **SalePrice**: The target variable (house price) that we are trying to predict.
- **YearBuilt**: The year the house was built.
- **LotArea**: The size of the lot in square feet.
- **OverallQual**: The overall quality rating of the house.
- **OverallCond**: The overall condition rating of the house.
- **GrLivArea**: Ground living area in square feet.
- **...** and many more.

## Model
- **Model Used**: Random Forest Regressor
- **Performance Metrics**: R-squared, Mean Absolute Error (MAE)
